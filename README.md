# Muhammad Ali Touheed — Portfolio

Personal portfolio of a Senior Android Developer (Kotlin · Java · Jetpack Compose · Firebase).

Built with pure **HTML, CSS, and vanilla JavaScript** — no frameworks, no build step.

## Run locally

Just open `index.html` in a browser, or serve the folder:

```
npx serve .
```

## Deploy

Push this repo to GitHub, then import it at [vercel.com](https://vercel.com) (or Netlify / GitHub Pages).
No build configuration needed — it's a static site.

After deploying, update the `og:url` / `og:image` meta tags in `index.html` with the live URL.
